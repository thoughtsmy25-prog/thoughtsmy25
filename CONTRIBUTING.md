# Contributing

Thank you for considering contributing to the Simple Interest Calculator project! All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork this repository.
2. Create a branch for your change:
   ```bash
   git checkout -b feature/your-change
   ```
3. Make your changes and test them locally.
4. Commit your work with a clear message:
   ```bash
   git commit -m "Add a clear description of the change"
   ```
5. Push your branch to your fork:
   ```bash
   git push origin feature/your-change
   ```
6. Open a pull request and explain what you changed and why.

## Reporting Bugs

When reporting a bug, please include:

- A clear and descriptive title.
- Steps to reproduce the issue.
- What you expected to happen.
- What actually happened.
- Your browser, operating system, and any relevant screenshots or error messages.

Please check existing issues before opening a new report so duplicate reports can be avoided.

## Suggesting Enhancements

Enhancement ideas are welcome. Explain the problem the suggestion would solve, the expected benefit, and any example of how the feature could work.

## Documentation Improvements

Corrections, clearer explanations, examples, and improvements to the README or other documentation are welcome. Keep the language clear and the instructions easy to follow.

## Pull Request Guidelines

- Keep each pull request focused on one change.
- Follow the existing project structure and coding style.
- Test your changes before submitting.
- Update documentation when your change affects usage or behavior.
- Describe the purpose of the change and link related issues when applicable.
- Be respectful and constructive during review.

## Community Standards

By participating, you agree to follow the project's [Code of Conduct](CODE_OF_CONDUCT).

## Questions

For questions or discussion, open an issue in this repository and provide enough detail for others to understand your concern.

Thank you for helping improve this project!
